# Kanora Beta

Closed beta downloads for **Kanora**, a Windows app that records gaming sessions on Android
handhelds over USB (adb).

This repository contains **no source code**, only the beta installers under
[Releases](../../releases). Each release lists the SHA-256 hash of the installer.

- A personal beta key is required; testers receive theirs directly.
- The installer is not code-signed yet, so Windows SmartScreen will warn. Please verify the
  SHA-256 hash before running it:
  `Get-FileHash "<path to installer>" -Algorithm SHA256`
